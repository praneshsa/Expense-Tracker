# 💰 Expense Tracker

A responsive, front-end Expense Tracker built using **HTML, CSS, and JavaScript** to manage personal income and expenses through a simple, interactive dashboard.

## ✨ Features

- **Dashboard Summary:** View total balance, income, expenses, and transaction count.
- **Transaction Management:** Add, edit, and delete income and expense records.
- **Category Management:** Organize transactions by Food, Transport, Shopping, Entertainment, Bills, Health, Education, Salary, Freelance, and Other.
- **Spending Visualization:** View expense distribution using a doughnut chart.
- **Search and Filter:** Search transactions by description and filter by category or transaction type.
- **Local Storage:** Automatically saves transaction data in your browser.
- **CSV Export:** Export transaction records for further analysis.
- **Responsive Design:** Works across desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- **HTML5** – Page structure and forms
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Application logic, DOM manipulation, and event handling
- **Chart.js** – Spending visualization
- **Local Storage API** – Browser-based data persistence

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- A code editor such as Visual Studio Code
- An internet connection for loading Chart.js from its CDN

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/praneshsa/Expense-Tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Expense-Tracker
   ```

3. Open the folder in Visual Studio Code:

   ```bash
   code .
   ```

4. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## 📖 How to Use

1. Enter a transaction description and amount.
2. Select a category and date.
3. Choose whether the transaction is income or an expense.
4. Click **Add Transaction**.
5. View the updated dashboard and spending chart.
6. Use the search and filters to find specific transactions.
7. Edit or delete transactions as needed.
8. Click **Export CSV** to download your transaction records.

## 💾 Data Storage

Transaction data is stored in the browser's `localStorage`. No backend server or database is required.

**Note:** Data is specific to the browser and device being used. Clearing browser storage may remove saved transactions. The application does not synchronize data across devices.
